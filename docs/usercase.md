# Thothsyn
thothsyn = Thoth + Synapse

一个浏览器插件,要求兼容chrome, chromium, edage, firefox, safari

是一个超级书签, 第一版功能主要是保存,分类查找,显示等功能
第二版功能需要有用户登录功能,用户用邮箱登录后, 可以同步保存的内容, 后台使用python3.14, fastapi框架来做

现在只做第一版内容

## 功能

### 选取内容
- 浏览器显示一个小图标, 点击小图标网页自动保存整个网页
- 右键小图标, 显示选项"整个网页保存”或者”部分保存"
- 如果点击部分保存, 按住左键拖动,保存某个或者某几个元素,元素的含义是DOM表上的内容, 功能类似于chrome检查页面里那个"Select an element in the page to inspect it"按钮功能, 直接拖动选中的元素统一选择就好,选中的dom自动高亮显示, 效果跟"Select an element in the page to inspect it"按钮一致即可
- 然后自动保存到书签里
- 保存内容自动选取标题,  url, 内容, 标题采取整页标题就好


### 展示内容
- 浏览器左边有一个侧边栏,平时最小化,或者有个方便的按钮,点击后出现左边侧边栏
- 点击侧边栏,会把内容按行排列显示,默认按收藏时间排就好, 排列可以只显示标题
- 鼠标移动到保存的内容的标题上(不显示链接,但标题可点击),侧边栏自动弹出一个窗口, 这个窗口是供快速浏览用,如果用户想仔细看,点击标题,直接作为浏览器tab打开


### 内容管理
- 内容管理建议采取树形控件展示, 类似linux命令`tree`展示的那种就可以
- 内容按tag管理, 选取某类tag
- 还可以按业务类型管理,比如分为"等待阅读, 存档"
- 第二版可以分享给别人, 分享的时候需要对方是thothsyn用户,如果不是建议安装插件
- 搜索,只支持按tag搜索, 所以可以单独对每个网页设置tag, 搜索的时候是在选项中选tag, 可以多选, tag选项是用户设置的所以tag, 可能需要有个本地简单数据库
  
### 用户管理
- 第二版用户注册,注册用email,验证email即可
- 用户要有等级标识,
  - 超级用户,就是管理员
  - 未验证邮件用户,未成功验证邮箱, 这样的没有同步功能
  - 正式用户,验证邮箱未付费
  - 付费用户 = 正式用户+付费

### 网页内容
1. 注册框, 在设置里有注册按钮,然后弹出注册弹窗 , 输入邮箱+密码即可
2. 需要有验证邮箱的链接,点击后自动升级为正式用户
3. 有付款链接,点击后出现付款弹窗, 这里出一个空弹窗吧, 白屏弹窗就好, 付款怎么支付我没想好
4. 付款完后自动成为付费用户
5. 付费用户可以线上保存自己的收藏,但要注意算法选择,保存原则是尽可能少占用空间,所以我建议:
     1. 如果是整个网页收藏的, 线上直接保存链接
     2. 如果是部分网页收藏的, 最好有个明确的保存方式,比如dom的html内容,这样我们占用空间会很小
     3. 数据库用supabase吧, 我机器上有docker,可以用docker安装用于测试
6. 设置里填个按钮, 类似”管理线上内容”, 点击后跳转到我们网页, 自己直接就登录了, 可以选择对自己的内容进行管理,比如删除
7. 用户功能包含修改密码,邮箱功能
### 其他
- 可以导入,包括从普通标签栏导入,第二版可以从自己账号同步
- 内容保存在本地,一个网页建议保存成一个单独文件
- 第二版本地内容和后台内容定期同步,以天为单位设置,也可以一键同步
- 第二版同步逻辑可选,包括: 本地增量线上, 线上增量本地, 互相增量取最大的内容集合
